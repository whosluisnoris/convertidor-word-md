Cómo usarlo y cómo preparar tu Word

      
Markdown solo entiende estructura: títulos, listas, tablas, énfasis. Si tu Word usa los estilos correctos, el resultado queda perfecto a la primera. Y si prefieres empezar desde cero, en Crear puedes escribir documentos y armar archivos de datos.

    


    

      

        
Usar el convertidor

        
    
          
  1. Abre index.html con doble clic. Se abre en tu navegador (Chrome o Edge).
    2. 
          
  2. Arrastra uno o varios archivos .docx a la zona blanca, o pulsa Elegir archivos.
    3. 
          
  3. Revisa el Markdown y la vista previa. Lee los consejos amarillos si aparecen.
    4. 
          
  4. Pulsa Descargar. Si el documento tiene imágenes recibirás un .zip con el .md y una carpeta imagenes/; descomprímelo y mantén ambos juntos.
    5. 
        

        
No necesita internet: puedes copiar la carpeta completa a una memoria USB y usarla en cualquier computadora.

Reglas de oro

        
    
          
  • Títulos con estilos, no con formato. Selecciona el texto y elige Título 1, Título 2… en Inicio › Estilos. Un texto grande y en negrita se queda como texto normal.
    • 
          
  • No saltes niveles. Después de un Título 1 va un Título 2, no un Título 4.
    • 
          
  • Listas con los botones de viñetas o numeración. No escribas guiones o números a mano. Usa Tab para crear subniveles.
    • 
          
  • Tablas sencillas. La primera fila es el encabezado. Evita combinar o dividir celdas y no pongas tablas dentro de tablas.
    • 
          
  • Imágenes “En línea con el texto” (Formato de imagen › Ajustar texto). Añade texto alternativo con clic derecho › Ver texto alternativo.
    • 
          
  • Una idea por párrafo. Usa Enter para separar párrafos; no uses líneas vacías para dar espacio.
    • 
          
  • Código: crea un estilo de párrafo llamado exactamente Código (fuente Consolas) y aplícalo a cada línea. La plantilla de ejemplo ya lo trae.
    • 
        

      


      

        
Lo que se pierde

        
    
          
  • Colores, fuentes, tamaños y resaltados.
    • 
          
  • Encabezados, pies de página y números de página.
    • 
          
  • Cuadros de texto, formas, SmartArt, WordArt y gráficos (conviértelos en imagen primero).
    • 
          
  • Celdas combinadas y alineación de tablas.
    • 
          
  • Comentarios y control de cambios (acéptalos antes de convertir).
    • 
          
  • Tablas de contenido automáticas (en Markdown sobran: los títulos ya son el índice).
    • 
          
  • Archivos .doc antiguos: ábrelos en Word y usa Guardar como › .docx.
    • 
        

      


      

        
Crear documentos y datos

        

          

            
Un documento (.md)

            
    
              
  1. Ve a Crear › Un documento y escribe como en Word.
    2. 
              
  2. Elige el tipo de texto en el botón amarillo (Párrafo, Título 1, Cita…) o escribe # y un espacio al inicio de una línea.
    3. 
              
  3. Con + Insertar agregas tablas, imágenes y secciones de datos en JSON o XML. Se llenan como un formulario y en el .md quedan como ```json o ```xml.
    4. 
              
  4. El botón Markdown muestra el texto tal cual se guarda; puedes corregirlo ahí y volver a Formateado (Ctrl+M).
    5. 
            

          

          

            
Datos (.json o .xml)

            
    
              
  1. Ve a Crear › Datos o elige una plantilla.
    2. 
              
  2. Pulsa + Agregar campo y elige qué quieres guardar. Ponle el nombre que quieras: la app escribe el nombre técnico por ti.
    3. 
              
  3. Para muchas filas usa una Tabla. Puedes pegar celdas copiadas de Excel directamente en ella.
    4. 
              
  4. Elige .json o .xml en Guardar como y pulsa Descargar.
    5.

Lo que escribes se guarda solo en este navegador, en tu computadora. Si una sección de datos tiene un error al corregirla a mano, la app te marca la línea antes de volver a la vista con formato.
